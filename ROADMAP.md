# Build Roadmap

## 0.1 — Launcher foundation (current)

- Native five-page interface
- HOME launcher registration
- Full-screen portrait display
- Installed-app browser and launch
- Live clock and persistent page selection
- External navigation handoff
- Read-only telemetry data contract

## 0.2 — Device integration

- Runtime location permission
- Live GPS speed, compass, and location
- Weather provider
- Android MediaSession listener and transport controls
- Configurable favorite applications

## 0.3 — OBD telemetry

- Bluetooth adapter selection and reconnection
- ELM327/OBDLink transport
- Standard read-only PIDs
- Validated RAM enhanced PIDs
- Logging, stale-data handling, and disconnect states

## 0.4 — Performance

- GPS/OBD synchronized 0–60 and quarter-mile timing
- Session history
- Acceleration graph
- Calibration and safe-use disclaimer

No CAN writes or vehicle-control commands are planned.
